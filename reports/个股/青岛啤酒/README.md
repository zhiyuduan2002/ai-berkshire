## 核心结论

**青岛啤酒 H 股是一门诚信干净、现金极厚、却已经不能涨价的生意**：剔除净现金后经营性业务仅 **4.4–6.7 倍 PE**、税后股息率 **6.07%**，下行有实物资产与分红托底；但两年产品结构升级只换来 **0.18%** 的吨价提升、创纪录毛利率约 **97%** 来自正在反转的大宗周期、**284 亿现金握在一个连续三年拒绝回购的代理人手里**——它值得作为**收息型深度价值仓**持有，不值得作为**复利仓**重仓。

四个维度罕见地给出了**同一个形状**的答案：**下限很高，上限很低。** 这不是一个有分歧的标的，是一个被各方一致认定为"便宜且安全，但不会变强"的标的。

巴菲特买入前 Checklist 得分 **5.5 / 10**——"资产与价格项全过，生意质量与资本配置项全不过"。

## 操作要点

| 项                                            | 内容                                                                                                                                |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **只买 H，不买 A**                      | 毛利率回吐 5pp 的压力测试下，H 剔现金 PE 走到约 9.9x（仍便宜），A 走到约 18x（**安全边际归零**）                              |
| 建仓价                                        | 稳健型可在现价**40.02 HKD** 建观察仓 / 收息仓；**36.00 HKD 以下为积极区**                                               |
| 仓位上限                                      | 单一仓位**不超过组合 10%**（因十年概率加权年化仅约 6.5–8.5%）                                                                |
| **不要因折价收敛而加仓**                | 32.21% 的 A/H 折价中约 20pp 是结构性的（股息税楔 + 买方授权结构不对称），不会收敛；可收敛的只有 5-10pp 治理折价                     |
| **升级触发器**（出现任一 = 可重估加仓） | ① 首次实质性回购注销；② 首次中期分红（2024 年已修章程增加条款但从未使用）；③ 股权激励重启；④ 总裁 / 财务总监 / 董秘三项聘任落地 |
| **降级触发器**                          | ① capex/D&A 持续 >1.3x 且无降本去向说明；② 再现 >20x PE 的非啤酒收购并完成交割；③ "其他品牌"连续两期 <−10% 且中高端增速 <+2%    |

## 方法学记录：Team Lead 任务书中被 Agent 纠正的 6 处基线数据错误

A 级信息丰富度下，最大的风险不是查不到，而是**抄到错的**。本次四个 Agent 独立纠正了 Team Lead 下发任务书中的 6 处错误，均已在各自报告中留痕：

| 项          | 任务书给定 | Agent 核实值                                                                                 |
| ----------- | ---------- | -------------------------------------------------------------------------------------------- |
| H 股股数    | ~3.48 亿股 | **655,069,178 股（48.02%）**；A 股 709,125,943 股                                      |
| 2025 年 DPS | 2.70 元    | **2.35 元人民币**（2.70 是港币口径，混用会虚增股息 17%）                               |
| H 股 PE     | 10.75x     | **10.13x**（行情商内含约 0.9065 的过期汇率）                                           |
| A/H 折价    | ~28%       | **32.21%**（同上汇率原因）                                                             |
| 2021 年 ROE | 7.55%      | **14.47%**（7.55% 是 2017 年；ROE 自 2022 年起平稳在约 15.3%，**并非上升趋势**） |
| 永顺泰代码  | 002956.SZ  | **001338.SZ**（002956 是西麦食品）                                                     |

**教训**：两源交叉验证不是形式要求。上表中任意一项若未被纠正，都会单独改变结论方向——尤其是 DPS 口径（直接决定"6% 股息率"是否成立）和 H 股股数（直接决定市值与净现金占比）。
