- F10"毛利率"= 1 −（原材料及易耗品 / 收入），**不含人工、租金、折旧**，与通常理解的餐饮毛利率不同；

## 2. 矛盾一：收入 +7.9%、净利 +0.5%、毛利率 −1.77pct、经营现金流 −13%

### 2.1 第一层：**增长不是来自餐厅，而是来自「低毛利的外卖 + 零售 + 加盟」**

2026H1 收入结构（RMB 千元，来源：中报分部附注 + 管理层讨论）：

| 收入构成 | 2026H1 | 2025H1 | 同比 | 对增量的贡献 |
|---|---|---|---|---|
| 海底捞餐厅经营 | 17,836,692 | 18,580,166 | **−4.0%** | — |
| 其他餐厅经营（21 个副牌，183 家） | 1,271,364 | 596,548 | +113.1% | — |
| ├─ **餐厅经营合计** | **19,108,056** | **19,176,714** | **−0.4%** | **−4.2%** |
| 外卖业务 | 2,051,445 | 927,620 | **+121.2%** | **+68.8%** |
| 调味品及食材销售 | 902,201 | 463,724 | **+94.6%** | **+26.8%** |
| 加盟业务 | 254,278 | 90,849 | **+179.9%** | **+10.0%** |
| 其他 | 20,926 | 44,387 | −52.9% | −1.4% |
| **合计** | **22,336,906** | **20,703,294** | **+7.89%** | 增量 16.336 亿 |

**核心门店指标全线走软**：
- 自营海底捞餐厅 **1,290 家 vs 1,322 家**（−32 家，−2.4%）
- 同店销售额 **16,348,861 vs 16,571,065 = −1.34%**；同店日均销售 **77.8 vs 78.9 = −1.39%**
- 顾客人均消费 **97.0 vs 97.9 元**（一线 104.2 vs 105.2，港澳台 196.6 vs 205.8，**全区间下降**）
- 翻台率 3.9 vs 3.8 次/天（**唯一改善项**，但同店翻台率 3.9 vs 3.9 持平 → 整体翻台率上升主要来自新店 4.2 与基数门店结构变化）

**结论（事实推出）**：翻台率微升 + 人均消费下降 + 同店销售下降 = **用降价换客流，没换来收入**。餐厅业务（占收入 85.5%）实际是**负增长**。

### 2.2 第二层：**增量收入的 90.3% 被两条成本线吃掉**

| 2026H1 占收入比 | 2026H1 | 2025H1 | 变化 | 同比金额 |
|---|---|---|---|---|
| 原材料及易耗品 | 41.59% | 39.82% | **+1.77pct** | +12.7% |
| 人工成本 | 31.76% | 33.75% | −2.00pct | +1.5% |
| 租金及相关 | 1.01% | 1.04% | −0.04pct | +4.0% |
| 水电 | 3.26% | 3.38% | −0.12pct | +4.0% |
| **折旧及摊销** | **4.06%** | **5.58%** | **−1.52pct** | **−21.5%** |
| 差旅及通讯 | 0.57% | 0.53% | +0.04pct | +15.1% |
| **其他开支** | **6.76%** | **5.25%** | **+1.51pct** | **+38.9%** |
| 其他收益及亏损 | −0.43% | +1.13% | **−1.57pct** | 摆动 −3.315 亿 |

**"其他开支 +38.9%"的全部来源**：外卖及其他平台费用 **585,351 vs 155,598 = +276.2%**（+4.298 亿）。中报附注 5 明确定义其为"外卖及其他平台所收取的流量获取费、外卖配送费及其他服务费"。

**增量经济性实算**：
```
增量收入             = 16.336 亿 RMB
增量原材料           = 10.457 亿  → 增量原材料率 64.0%（存量业务仅 39.82%）
增量外卖平台费       =  4.298 亿  → 占增量收入 26.3%
两项合计吞掉增量收入的 90.3%
```

**即：每新增 1 元收入，0.64 元给了供应商、0.26 元给了美团/抖音等平台，只剩 0.097 元去覆盖人工、租金、水电、折旧。** 这就是"收入 +7.9%、净利 +0.5%"的全部答案——**增长是真的，但这种增长的边际利润接近零**。

**反面论据**：外卖与零售的**边际贡献仍为正**（9.7% > 0），且它们不需要新开门店、不占用新资本，理论上 ROIC 可以很高；调味品业务（+94.6%）若能做成独立品牌，长期毛利结构优于餐厅。此外人工成本率下降 2.00pct 是真实的经营杠杆改善（人工仅 +1.5% 而收入 +7.9%）。所以不能简单判定"增长无价值"，只能判定**"当前阶段增长不创造利润"**。

**判断（事实推出）**：这不是"利润是假的"，而是**"浮存红利在退潮"**。疫后餐饮的供应链账期和预付卡（合约负债）曾经给过海底捞一笔无息资金，现在收入结构转向外卖/零售（对平台是应收、对供应商是现结），这笔浮存正在反向释放。

**反面论据**：应付账款下降也可能是议价能力下降（供应商要求更短账期）的信号，若如此则属结构性恶化而非一次性正常化。目前数据无法区分两者——需跟踪 2026 年报的应付周转天数。标注为**待验证**。

### 2.4 矛盾一的最锋利一刀：**核心经营利润 +4.4%，但核心 EBITDA −4.0%**

```
2026H1 核心经营利润 25.135 亿 vs 2025H1 24.081 亿  →  +4.4%
2026H1 核心 EBITDA  34.214 亿 vs 2025H1 35.640 亿  →  −4.0%
差额全部来自折旧摊销下降 2.480 亿（11.559 → 9.079 亿，−21.5%）
核心 EBITDA 率 15.32% vs 17.21%  →  −1.89pct
```

**这是本次中报最重要的一个数**：公司呈现的"核心经营利润增长 4.4%"与"净利 +0.5%"，**在扣除会计折旧的口径下其实是 −4.0% 的下滑**。PP&E 折旧从 784,924 降到 534,726（**−31.9%**），而同期资本开支从 7.264 亿升到 7.776 亿（**+7.1%**）。**折旧在减、资本开支在增，这个剪刀差不可能长期持续**。详见 §3.3 的敏感性测算。

## 3. 盈利能力：ROE 39.6% 到底是什么撑起来的

### 3.1 杜邦三因子分解（实算，口径写明）

**答案：ROE 39.6% 的主引擎不是杠杆，而是资产周转率。**

### 3.2 权益乘数只有 2.19×，且其中 18.4% 是 IFRS 16 的会计产物

```
IFRS 16 对权益乘数的贡献 = 2.1850 − 1.7835 = 0.4014x，占 18.4%
```

**更关键的事实：海底捞根本没有金融杠杆。** 2026-06-30 负债拆解（RMB 亿）：

2. **净营运资本 −23.59 亿**（负营运资本 = 顾客和供应商在无息给公司垫资，即巴菲特所说的"浮存"）

### 3.3 ROIC：真正的护城河证据，也是最大的会计陷阱所在

```
有效税率（TTM）= 16.9054 / 57.4183 = 29.44%
NOPAT = 核心经营利润 55.086 × (1 − 29.44%) = 38.867 亿 RMB

投入资本 = PP&E 35.070 + 使用权资产 27.397 + 净营运资本 (−23.589) + 商誉 0.848 + 无形 0.498
         = 40.225 亿 RMB

ROIC = 38.867 / 40.225 = 96.6%
ROIC（额外保留营收 2% = 8.97 亿经营现金）= 79.0%
ROIC（剔除使用权资产，即视租赁为表外）= 303.0%
```

**ROIC 79%–97%（税后）。** 这是极高的资本回报率——按巴菲特的标准，这是"高质量生意"的硬指标。原因清晰：**门店是租来的（不占资本），顾客预付/供应商账期提供负营运资本，公司只需投入装修和设备。**

**反面论据（必须说，而且很重**：
1. **高 ROIC 遇上收缩的门店数 = 无处可投。** 自营门店 1,322 → 1,290，FY2025 大陆自营 1,281 vs FY2024 1,332。96.6% 的 ROIC 若没有增量门店可投，就只能变成股息，**不能复利**。巴菲特买的是"能把留存利润按高 ROIC 再投入"的生意；海底捞现在是"高 ROIC 但没有再投入空间"的生意——**这两者的内在价值差一个数量级**。
2. **ROE 还被高派息人为抬高。** 母公司权益 115.27 → 104.34 → 100.14 → 97.65 亿，连续四期下降。分母缩小本身就在推高 ROE。把 84%–129% 的利润发出去，ROE 自然好看，但这是"分母管理"不是"分子改善"。
3. **折旧低估使 ROIC 和净利同时虚高。** PP&E 折旧 TTM 仅 11.72 亿 vs FY2024 的 18.08 亿，缺口 6.36 亿。敏感性：

```
若 PP&E 折旧回到 FY2024 水平：
  税前利润 −6.360 亿 → 税后净利 −4.487 亿 = TTM 净利的 11.1%
  调整后 EPS = 0.6475 RMB（原 0.7281）
  调整后 PE（9.115 HKD）= 12.01x （原 10.68x）
```
而同期资本开支从 FY2023 的 6.31 亿升到 TTM 的 17.41 亿（**+176%**），capex/D&A 从 0.21× 升到 0.90×。**过去三年的"折旧顺风"来自 FY2021-2022 关店减值后资产基数骤降 + FY2023 的极低资本开支，这两个条件都已消失。**

## 4. 现金流质量：IFRS 16 的扭曲方向与「真实自由现金流」

### 4.1 IFRS 16 的扭曲方向（必须讲清，否则所有现金流指标都是错的）

**IFRS 16 之前**：门店租金是经营费用，**全额扣减 OCF**。
**IFRS 16 之后**：租金被拆成两块——
- **使用权资产折旧**（非现金，加回 OCF）
- **租赁利息**（计入财务成本；实付利息可放经营或筹资，海底捞放在筹资的"已付利息"）
- **租赁本金偿还**放在**筹资活动**

**方向结论：IFRS 16 系统性地「虚增」OCF 与 EBITDA，虚增幅度 ≈ 租金现金支出。** 海底捞 2026H1 利润表上的"租金及相关开支"只有 2.248 亿（占收入 1.01%），而实际租赁现金流出 = 偿还租赁本金 4.339 亿 + 租赁利息（估计 0.6–0.8 亿）。**也就是说，报表上的"租金"只反映了真实租金支出的约 1/3。**

因此本报告定义：
```
FCF（常规口径）  = OCF − 资本开支
真实 FCF（还原口径）= OCF − 资本开支 − 租赁本金偿还   ← 巴菲特意义上的"业主盈余"更接近这个
```

### 4.2 真实自由现金流序列：三年腰斩再腰斩

| 期间 | OCF | 资本开支 | 租赁本金 | FCF | **真实 FCF** | 已付股息 | **股息/真实FCF** |
|---|---|---|---|---|---|---|---|
| FY2023 | 90.00 | 6.31 | 8.81 | 83.70 | **74.89** | 5.54 | **7.4%** |
| FY2024 | 76.34 | 13.09 | 8.92 | 63.25 | **54.33** | 60.71 | **111.7%** |
| FY2025 | 56.64 | 17.48 | 10.24 | 39.16 | **28.92** | 41.33 | **142.9%** |
| **TTM** | **53.19** | **17.41** | **9.57** | **35.78** | **26.21** | **34.07** | **130.0%** |

（单位：亿 RMB）

**真实 FCF 三年下滑 65.0%（74.89 → 26.21 亿），而归母净利同期仅下滑 9.8%（44.99 → 40.58 亿）。**

OCF / 净利润 = **1.31×**（TTM）。表面健康（>1），但这个 1.31× 里有约 0.48× 是 IFRS 16 加回的折旧（19.34 亿 / 40.58 亿）。**剔除 IFRS 16 口径后，真实 FCF / 净利润 = 26.21 / 40.58 = 0.65×** ——每赚 1 元账面利润，只有 0.65 元是股东能自由支配的现金。

### 4.3 矛盾三：FY2023 → FY2025 的 OCF −33.36 亿怎么来的

```
经营所得现金（税前）  99.81 → 74.76  变化 −25.05 亿   （75.1%）
已付所得税          −9.80 → −18.11  变化  −8.31 亿   （24.9%）← 现金税正常化
────────────────────────────────────────────────
OCF                90.00 → 56.64  合计 −33.36 亿
同期归母净利         44.99 → 40.50       仅 −4.49 亿
```

进一步拆解 −25.05 亿的税前部分（基于 §2.3 同口径方法）：
- **真实盈利能力下滑约 −10.3 亿（31%）**：核心 EBITDA 从 FY2023 的约 81.8 亿（52.465 + 29.378 估计）降到 FY2025 的 75.85 亿；
- **营运资本顺风消失约 −14.7 亿（44%）**：FY2023 营运资本贡献 +13.57 亿（疫后应付账款与预付卡集中膨胀），FY2025 转为 −1.16 亿；
- **现金税正常化 −8.31 亿（25%）**：FY2023 仅付 9.80 亿现金税（有 FY2021 的 41.63 亿亏损可结转抵扣），FY2025 付 18.11 亿。有效现金税率从 FY2023 的约 17% 回到 FY2025 的约 31%。

**答案：现金流跌幅（−37%）远大于利润跌幅（−10%），因为 FY2023 的现金流本身是「三重一次性顺风」叠加出来的峰值——疫后浮存膨胀 + 亏损结转免税 + 极低资本开支。这三项全部已经耗尽。** FY2023 的 90 亿 OCF **不是正常化水平**，用它做基准会严重高估公司的现金创造力。

**反面论据**：反向也成立——**TTM 的 26.21 亿真实 FCF 也可能是低估**。因为：(a) 资本开支 17.41 亿中含门店翻新的"追赶性支出"（FY2023 只花 6.31 亿，欠投资），稳态维护性资本开支可能在 11–13 亿（以 PP&E 折旧 11.72 亿为代理，**估计**）；(b) 营运资本的负向释放是一次性的，不会年年发生。按维护性资本开支 12 亿、营运资本中性测算，**稳态真实 FCF 约 31–34 亿 RMB（估计）**。这个数字在后面的估值里会用到。

### 6.3 股息覆盖率：这是全篇最大的红灯

```

```

**用 IFRS 16 还原后的真实自由现金流衡量，海底捞过去 12 个月的分红是其自由现金流的 1.30 倍。FY2025 是 1.43 倍，FY2024 是 1.12 倍——已经连续三年超发。** 差额由现金池填补（银行结余 −36.5%）和新增银行借款（2026H1 +25.62 亿）支撑。

**股息可持续性测算**：
```
若将派息率压到真实 FCF 的 80%（审慎水平）：
  DPS = 26.21 亿 × 80% / 0.85344 / 55.74 亿股 = 0.4407 HKD
  → 当前价股息率降至 4.84%
  → DDM 估值（r=10%, g=0）= 0.4407 / 0.10 = 4.41 HKD

  DPS = 0.52–0.57 HKD → 股息率 5.7%–6.3%
```

**反面论据（股息可能并不会砍）**：
1. 公司账上净现金 65.50 亿（中口径），**理论上可以在不砍股息的情况下再超发 8 年**；
2. 资本开支的"追赶期"（翻新老店）一旦结束，capex 回落到 12 亿，真实 FCF 可回升至 31–34 亿，覆盖率回到 100% 附近；
3. 管理层 2026 年改为**直接以 HKD 宣派股息**，显示出维护港币投资者回报的意愿；
4. 创始人家族（张勇、舒萍等）持股比例高，股息是其主要现金来源，**有强动机维持分红**。

**但：第 4 点同时也是风险** —— 大股东依赖股息，可能导致公司在现金流不足时仍然借钱分红，损害长期资本配置。这需要由"风险与管理层"维度的同事进一步验证。

## 10. 什么情况下这笔投资会亏钱

按概率与杀伤力排序（全部基于已披露数据的外推，非假想风险）：

### 风险 1：股息被砍（杀伤力最大，概率中高）
- **事实基础**：TTM 股息 34.07 亿 = 真实 FCF 26.21 亿的 **130.0%**；FY2025 为 **142.9%**；FY2024 为 **111.7%**。连续三年超发。
- **融资痕迹**：银行结余 93.30 → 59.29 亿（−36.5%）；2026H1 新增银行借款 25.62 亿。
- **已在发生**：DPS 1.215（2024）→ 0.845（2025）→ 0.761（TTM），**已累计 −37.4%**。
- **亏钱路径**：若 DPS 砍至真实 FCF 的 80%（0.4407 HKD），按 DDM（r=10%, g=0）估值 **4.41 HKD**，即从 9.115 **再跌 52%**。即使只砍到 0.60 HKD、PE 维持 10.68×，持有者损失的是从 8.35% 跌到 6.6% 的收益率，股价大概率同步下调 20%。
- **监控指标**：2026 年报的"已付股息 / (OCF − capex − 租赁本金)"是否降到 100% 以下；银行结余是否止跌。

### 风险 2：折旧顺风反转（杀伤力中等，概率高）
- **事实基础**：PP&E 折旧 TTM 11.72 亿 vs FY2024 18.08 亿（**缺口 6.36 亿**）；而资本开支 FY2023 6.31 → FY2024 13.09 → FY2025 17.48 → TTM 17.41 亿（**+176%**）。capex/D&A 从 0.21× 升至 0.90×。
- **亏钱路径**：折旧回到 FY2024 水平 → 净利 −4.49 亿（−11.1%）→ PE 从 10.68× **跳到 12.01×**。若市场同时把 PE 压到 10×，股价 = 0.6475/0.85344 × 10 = **7.59 HKD**（−17%）。
- **这是一个几乎确定会发生的事件**，只是时间问题。

### 风险 3：外卖/零售持续替代堂食，净利率结构性下移（杀伤力大，概率中）
- **事实基础**：增量收入 68.8% 来自外卖，但增量原材料率 **64.0%**（存量 39.82%）、外卖平台费 **+276.2%** 吃掉增量的 26.3%，**两项合计吞掉增量收入的 90.3%**。
- **亏钱路径**：外卖占比从 9.2% 升到 20%，若其边际利润率仅 5%（平台抽成持续上行），混合净利率将从 9.05% 降至约 7.5%。TTM 净利 → 33.6 亿，EPS → 0.706 HKD；按 PE 10× = **7.06 HKD**（−23%）；按衰退定价 PE 9× = **6.36 HKD**（−30%）。
- **监控指标**：外卖及其他平台费用 / 外卖业务收入 的比率（2026H1 = 585,351/2,051,445 = **28.5%**；2025H1 = 155,598/927,620 = **16.8%**，**一年内上升 11.7pct**）——这是最关键的单一先行指标。

### 风险 4：同店销售与门店数持续双降（杀伤力大，概率中）
- **事实基础**：同店销售 −1.34%、同店日均 −1.39%、人均消费 97.0 vs 97.9（全区间下降）、自营门店 1,290 vs 1,322（−32 家）。
- **行业背景**：呷哺收入 −23.1%、九毛九 −13.2%，中式连锁餐饮整体收缩。
- **亏钱路径**：若 EPS 年降 7.5%（悲观情景），3 年后 EPS 0.68 HKD、PE 9× → **6.1 HKD**（−33.3%）。
- **注意**：此情景下 8.35% 的股息也会同步下调，**股息和股价会同时受损，不存在"股息补偿股价下跌"的对冲**。

### 风险 5：营运资本浮存继续反向释放（杀伤力中，概率中）
- **事实基础**：2026H1 营运资本 −3.04 亿 vs 2025H1 +1.27 亿（摆动 −4.31 亿）；贸易应付 −2.42 亿、其他应付 −2.73 亿、合约负债 −0.28 亿。净营运资本 −23.59 亿（占收入 −5.3%）。
- **亏钱路径**：若负营运资本从 −23.59 亿收敛到 −10 亿，将一次性消耗 13.6 亿现金，相当于 TTM 真实 FCF 的 52%，直接压缩分红能力。
- **监控指标**：应付账款周转天数、合约负债（预付卡）余额。

## 11. 本维度结论与评分

### 11.1 对核心问题的直接回答

**「这是真便宜，还是低 PE 陷阱？」——两者都是，取决于你买的价格。**

**真便宜的证据（硬数据）**：
1. PE 10.68× 与 PB 4.44× 均为**上市以来最低**，价格分位 1.0%，估值分位 ≈ 0%；
2. 价格跌幅 −46.7% 是盈利跌幅 −13.8% 的 **3.4 倍**，所以这**不是**"价格跌了但估值没跌"的假便宜；
3. ROIC 79%–97%（税后）、ROA 18.05%、净利率 9.05%，**全部为同业第一或第二**；
4. 净现金 35–86 亿（占市值 8%–20%），剔净现金 PE 8.57–9.07×，EV/EBITDA 5.1–5.8×；
5. 税后股息率 **8.35%**（红筹 0% 预扣），对一个 ROIC 近 100% 的生意，这个收益率在全球餐饮龙头中极其罕见。

**低 PE 陷阱的证据（同样是硬数据）**：
1. 增量收入的 **90.3%** 被原材料和平台费吃掉，**增长不创造利润**；
2. 核心经营利润 +4.4% 但**核心 EBITDA −4.0%**，差额全部来自折旧下降 2.48 亿——**会计顺风掩盖了真实恶化**；
3. 真实 FCF 三年 **−65.0%**（74.89 → 26.21 亿），而净利仅 −9.8%；
4. 分红是真实 FCF 的 **130.0%**，DPS 已两年 **−37.4%**，8.35% 的股息率**不是可依赖的下限**；
5. 自营门店 −32 家、同店销售 −1.34%、人均消费全区间下降——**高 ROIC 碰上无处可投，复利机器变成清算式分红机器**。

**结论**：TTM EPS 0.853 HKD **含约 11% 的会计水分**（折旧低估）。按干净 EPS 0.759 HKD 计算，当前 PE 实为 **12.01×**，对一个零增长、门店净减、分红超发的生意，12× 不便宜。
**但**净现金垫 + 79%–97% 的 ROIC + 历史最低估值，意味着下行空间有限而上行弹性大。
**所以：现在不买，等 7.3–7.8 HKD（折价 22%–27%）建半仓，6.5 以下加满。若持有意愿强，8.3–8.5 可先建 1/3 仓。**

**巴菲特的话用在这里最贴切**：

> "时间是优秀生意的朋友，是平庸生意的敌人。"

海底捞的 ROIC（79%–97%）属于"优秀生意"，但它的同店销售（−1.34%）、门店数（−2.4%）、真实自由现金流（三年 −65%）属于"时间在变成敌人"的那一类。**这两件事同时为真，这就是为什么它的 PE 跌到了上市以来最低——市场不是在定价它的资本回报率，而是在定价它的再投资空间。**

> "以合理的价格买入一家优秀的公司，远胜于以优秀的价格买入一家平庸的公司。"

海底捞现在的问题不是"公司不够优秀"，而是**9.115 HKD 这个价格对应的折价（9%）不够合理**。段永平的话更直接：**"看不懂就不要买"**——外卖业务的边际利润率能否稳定在 10%、折旧什么时候回升、股息会不会砍，这三件事**今天都看不清**。所以答案是：**等价格给够补偿，再买这个看不清。**
